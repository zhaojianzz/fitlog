# 练吃睡记录

手机上记录训练、饮食（蛋白质）、睡眠、体重和腰围的网页，带图表和 CSV 导出。
数据只保存在你手机的浏览器里，不上传到任何服务器。

## 部署到 GitHub Pages（免费，一次性）

1. 注册并登录 GitHub。
2. 右上角 **+** → **New repository**：名字填 `fitlog`，选 **Public**（免费账号的 Pages 只支持公开仓库；公开的只是代码，你的数据不在里面），点 **Create repository**。
3. 在新仓库页面点 **uploading an existing file**，把这 4 个文件拖进去：`index.html`、`sw.js`、`manifest.json`、`icon.png`，点 **Commit changes**。
4. 仓库的 **Settings** → 左侧 **Pages** → **Source** 选 **Deploy from a branch**，Branch 选 `main`、文件夹 `/ (root)`，点 **Save**。
5. 等 1–2 分钟，页面顶部会显示网址：`https://你的用户名.github.io/fitlog/`。

## 装到 iPhone 主屏幕

1. 用 **Safari** 打开上面的网址。
2. 点底部的分享按钮 → **添加到主屏幕**。
3. 以后都从主屏幕的「练吃睡」图标打开。

一定要从主屏幕图标打开：在 Safari 里直接访问的网站，长时间不打开时数据可能被系统清理；添加到主屏幕后不受这个限制。

## 使用

- **训练**：自动建议今天练 A 还是 B，显示上次的重量和次数，以及该不该加重。填重量，用 −／＋ 调次数，点「记一组」。点已记录的组可以删除。
- **饮食**：点按钮记一餐，顶部累计当天蛋白质。不在按钮里的食物用「自定义」，可以顺手存成新按钮。
- **身体**：上床／起床时间、晨重、腰围（每周一次）、精力、酸痛，改完自动保存。
- **图表**：晨重（含 7 天平均）、腰围、睡眠、蛋白质、每个动作的力量趋势。
- **数据**：
  - 导出 CSV：训练、饮食、身体三份，分析时发给 Claude。
  - **备份**：每周点一次，把 JSON 文件存到「文件」App 或发给自己。换手机或误删时用「从备份恢复」。

## 修改

- 动作、目标次数：改 `index.html` 开头的 `PLAN`。
- 蛋白质目标：改 `PROTEIN_TARGET`。
- 修改后在 GitHub 仓库里重新上传 `index.html` 覆盖即可，数据不受影响。
